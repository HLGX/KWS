# KWS — VOD chat keyword search

Search Twitch, Kick, SOOP, YouTube and CHZZK VOD chat logs for keywords, and jump straight to the moment in the VOD.

## Download
**[⬇ Download the latest version (KWS.zip)](https://github.com/HLGX/KWS/releases/latest/download/KWS.zip)**

Older versions and change notes: [Releases](https://github.com/HLGX/KWS/releases)

## Install (Chrome)
1. Unzip `KWS.zip` into a folder you'll keep (don't delete it later).
2. Open `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the unzipped folder.

## Update
Download the new `KWS.zip`, unzip it **over the same folder** (replace files), then press the ↻ reload button on KWS in `chrome://extensions`. Your history and settings are kept.
